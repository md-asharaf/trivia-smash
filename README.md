# TriviaSmash 3D

A high-speed 3D table tennis trivia game where your reflexes meet your knowledge! Return the serve by smashing the ball into the correct answer to build your streak and rack up high scores.

## Features

- **Dynamic 3D Physics:** Realistic paddle tracking using raw cursor velocity. Master the Smash, Drive, and Drop Shot!
- **Endless Trivia:** Dynamically generated questions keep the game going in 10-question rounds.
- **Modern UI:** Sleek glassmorphism UI, gorgeous 3D environments, and satisfying confetti explosions.
- **Interactive Audio:** Immersive paddle hits, table bounces, and streak sound effects.

## How to Play

1. Read the question displayed at the top of the screen.
2. 4 opponent paddles on the other side of the table represent 4 possible answers.
3. When the ball is served, move your mouse to control your 3D paddle.
4. **Hit the ball** towards the opponent paddle holding the correct answer!
   - *Tip: Thrust your mouse forward on impact to Smash, or pull back for a slow Drop Shot!*
5. Build your streak, but be careful—one wrong answer resets your streak to zero!

## Tech Stack

- React
- React Three Fiber & Drei (3D Rendering)
- Three.js
- Vite
- Lucide React (Icons)
- Canvas Confetti

## Getting Started

1. Clone the repository
2. Run `npm install`
3. Run `npm run dev` to start the local development server
4. Open your browser to `http://localhost:5173` and play!
